# D - The Personal Assistant Product Requirements

## Phase 0 objective
Establish a safe, testable foundation for a Windows-first personal AI operating assistant. Phase 0 includes the backend service, frontend shell, optional desktop packaging, configuration, persistence foundation, shared contracts, and security interfaces.

## Non-goals
No computer control, terminal execution, browser automation, voice, autonomous loops, file deletion, or provider-dependent reasoning is enabled in Phase 0.
