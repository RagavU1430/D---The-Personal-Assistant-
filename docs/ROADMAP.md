Phase 5 introduces controlled developer tools (Git suite, test execution with auto-detection, log diagnostics, and allowlisted CLI commands) bounded strictly by `APPROVED_WORKING_ROOTS` and `COMMAND_ALLOWLIST` without arbitrary shell access.

Phase 3 uses registered computer tools, a Windows controller abstraction, an application allowlist, emergency stop, lifecycle states, and a legitimate per-user Startup-folder manager. Browser automation, voice, continuous vision, destructive file operations, unrestricted terminal access, and autonomous workflows remain out of scope.
